# Build Log — 2026-06-05

Session theme: **SEAS V3 — the self-correcting reasoning spine.** SEAS stopped
faking research and started producing genuine, evidence-grounded findings; Argo
gained durable learning from screenshots and user-pointed URLs; and we built an
objective model benchmark. All on `main`, github.com/yiyaw-lab/seas, live on

## TL;DR
The vision sharpened from "auto-incorporate frontier capabilities" to **a
cognitive architecture that holds beliefs, adversarially tests them against
external reality, and revises its world model** (this is V3, wrapping the V2
insight engine). We built the reasoning-spine floor: a Finding stage that did not
exist before, gated so a finding must cite real evidence and a falsifiable
prediction or it is rejected. Plus: Argo learns from images and URLs, a
cross-provider model benchmark, and several live-bot fixes. Design lives in a
private plan file; this log is the public record.

## 1. The V3 reframe (why this is a new version)
ARGO_V2 designed the insight engine: `Signal → Observation → Insight → Bet`.
V3 wraps it in a **belief → externally-grounded critique → revision** loop. The
center of gravity is the reasoning spine; "auto-incorporating capabilities" is
demoted to a consequence. The critic is grounded in three external checks
(verification, SEAS findings, recorded predictions) — never a same-model persona,
which is confabulation theater. Deep recursion is safe *because* each layer must
consume new external evidence or terminate.

## 2. SEAS rebuilt — from templated cards to genuine findings
The old pipeline was hollow: `experiment.py` was an f-string (every signal → the
same three "experiment cards"), and there was **no Finding stage in the code at
all**. F-001 was hand-authored, its "experiments" never ran. So "make SEAS
produce genuine findings" meant *building the Finding stage*.

Four new modules, one shared contract:
- **`seas_schema.py`** — the Finding schema + **emission gate**. A finding is
  rejected unless it has external cited evidence, a falsifiable dated prediction,
  and a refutation condition. This is what stops SEAS laundering a signal's own
  description back out as a "finding."
- **`world_model.py`** — beliefs Argo holds. Confidence moves ONLY via evidence
  or a scored prediction (there is no `set_confidence`). Legacy F-001 seeds at
  0.3 / `unverified` and must earn its way up.
- **`probes.py`** — dead-end memory (a probe, not a silent drop) with three
  outcomes: `inconclusive` / `premature` / `unreachable`. Plus a per-source
  **failure ledger**: a single 503 never escalates; a feed removal needs ≥3 hard
  failures over ≥48h (time, not count). `unreachable` routes to self-heal, gated
  on persistence so a 5-min outage can't trigger a delete-feed PR.
- **`seas_finding.py`** — Stage 1 synthesis floor. Fetch real sources, the model
  PROPOSES a structured judgment, the deterministic gate DISPOSES → a cited
  finding (+ seeded belief) or an honest probe. Reuses `argo_observe`'s guarded
  call + `web_fetch`.

Keystone fix: `fetch_signals.to_signal()` was capturing each signal's source
**link and throwing it away** — Stage 1 needs it to fetch the page behind a
signal.

Documented per finding (full provenance): the finding JSON, a `runs/<id>/` source
bundle (the cited evidence archived), and a linked belief in the world model.

## 3. Closing the clustering gap — Firecrawl (narrow, optional)
One signal batch is stratified-diverse by design, so reusing sibling signals
never gave a topical pool → everything probed `premature`. Fix: on-demand topical
SEARCH via Firecrawl (`firecrawl_client.py`), called over REST with urllib (no
SDK, no pip dep), activated only by `FIRECRAWL_API_KEY`. The host allowlist is
re-applied to results, so Firecrawl sits *inside* our security boundary. Also a
`web_fetch` fallback for JS/403 pages.

## 4. Argo learns from the user's feed
- **Screenshots** (`taste_signals.py`): the webhook only read `msg['text']`, so
  photos were silently dropped. Now a photo (or an image sent as a *document* —
  the second bug) goes to Claude vision, which extracts a **durable taste signal**
  (the transferable pattern + why it works), persisted and folded into project
  generation. Soft preference, so deliberately NOT routed through the finding
  gate or world model.
- **User-pointed URLs** (`study_url`): she can now point Argo at ANY source, even
  off-allowlist. Principle: a user-directed fetch ≠ autonomous browsing — she's
  the trust gate. SSRF guard stays non-negotiable (internal/metadata IPs always
  refused); content returns wrapped as UNTRUSTED data so a page can't hijack
  Argo's PR/write tools. Autonomous fetching stays allowlist-locked.

## 5. Objective model benchmark
`seas_benchmark.py` A/Bs models on the SAME synthesis task, scored by the
emission gate (pass rate, sources cited, quote-fidelity, latency, **cost**,
throttle count). Fairness by construction: sources fetched once, replayed to every
model. It already paid off — caught the gate being passable with **fabricated
quotes** (a model cited a source with an invented quote), which we then closed:
`validate_finding(finding, sources=...)` now verifies quotes are real substrings.

## 6. Live-bot reliability fixes
- **Tool deadline guard**: a tool that ran past the MCP connector's fixed 300s
  budget left the user with 5 minutes of silence. Every tool now has a
  wall-clock cap well under 300s and fails fast with a clear message.
- **Instant ack + heartbeat**: tool-bound turns now ack in <1s and send periodic
  "still working" nudges, so a long turn is never silent.
- **`openai>=1.55` pin**: fixed `httpx 0.28 'proxies'` TypeError that had killed
  the gpt path.

## Model benchmark — decided
17-trial cost-benefit run (sources held constant, scored by the gate):

| model | findings | pass% | qv% | throttled | $/finding |
|---|---|---|---|---|---|
| Opus 4.8 | 4 | 100 | 100 | 0 | $527/k |
| Sonnet 4.6 | 7 | 58 | 96 | 0 | $68/k |
| gpt-5 | 9 | 82 | 100 | 6 | $24/k |
| gpt-5-mini | 9 | 64 | 100 | 0 | $5/k |

Opus is the most disciplined (100% pass, 0 overclaims) but ~100x mini's cost.
gpt-5-mini is the raw cost-benefit winner ($5/finding, no throttling). **Chose
`ARGO_MODEL=gpt-5` for SEAS** — best quality among the cheap models (82% pass,
fewer overclaims), keeping the belief system cleaner at the source; ~22x cheaper
than Opus. Accepted risk: gpt-5 threw 6 throttled calls on this tier (fine for a
cron, retried). Chat stays on Sonnet (latency). `read_taste`/`read_findings` make
the model's inputs inspectable.

## Finding STYLE per model (and a benchmark limit worth naming)
The verdict patterns are behavioral fingerprints even without the finding text
(which the benchmark discarded — it kept metrics, not claims):
- **Opus 4.8** — cautious senior: 4 findings / 13 probes, 100% pass, 0 overclaims.
  Rare, high-conviction. Almost certainly walked past real findings the others
  caught (4 vs gpt-5's 9 on identical inputs). Caution = fewer false beliefs, but
  leaves signal on the table.
- **gpt-5** — strong analyst: 9 findings, 82% pass, 2 overclaims. Best balance of
  "finds a lot" and "rarely wrong." Why it was chosen.
- **gpt-5-mini** — eager junior: 9 findings but 5 overclaims (wide net, gate as
  editor). 100% fidelity — its slips were structural, never fabricated quotes.
- **Sonnet 4.6** — wildcard: 7 findings, and the ONLY model under 100% qv (96%) —
  one near-fabricated quote slipped to the gate edge. Least precise on evidence.

**The limit this exposes:** the gate measures *correctness* (structure + quote
fidelity), NOT *insight*. A model can pass 100% with sound-but-boring findings.
Opus's discipline proves its findings are sound, not that they're interesting. So
"is Opus worth it?" → for SEAS, no: the gate already guarantees soundness, so you
want the model that finds the MOST sound things (gpt-5, 9@82%), not the fewest
perfect ones (Opus, 4@100%). Opus's caution earns its price only where a single
wrong belief is catastrophic — SEAS isn't that (predictions loop catches wrong
findings downstream). A future benchmark dimension should score the V2 "surprise
test" (would Yiya not have thought of this?) — but that needs a judge, not the
deterministic gate.
