# Argo V1 Success Criteria

Argo is successful if:

1. It recommends projects Yiya would not have chosen herself.

2. Those projects generate high energy.

3. High-energy projects get built.

4. Built projects generate artifacts.

5. Artifacts strengthen:
   - SEAS
   - Argo
   - Future opportunities
