# SEAS Opportunity Heuristics

A great opportunity should satisfy multiple dimensions.

1. Capability Gain
Does it teach something valuable?

2. Artifact Potential
Can it become a repo, demo, benchmark, dataset, or tool?

3. Ecosystem Leverage
Does it strengthen SEAS, OCII, Synapi, or future systems?

4. Builder Signaling
Would frontier builders find it interesting?

5. Originality
Is it a surprising interpretation of the signal?

6. Frontierness
Does it touch the edge of current capability?

7. Delight
Would Yiya genuinely want to build it?
