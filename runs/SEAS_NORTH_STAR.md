# SEAS North Star

SEAS is not a capability database.

SEAS is not a signal database.

SEAS is not a project tracker.

SEAS is a capability acquisition engine.

The primary output of SEAS is:

A weekly experiment that:

1. Uses frontier developments.
2. Builds a valuable capability.
3. Produces a public artifact.
4. Makes Yiya feel excited to build it.

Success Metric:

Every Monday SEAS generates one experiment that is more compelling than what Yiya would have chosen herself.
