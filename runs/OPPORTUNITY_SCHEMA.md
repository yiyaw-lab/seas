# SEAS Opportunity Schema

An opportunity is a frontier development that can be transformed into:

- capability gain
- a public artifact
- reputation building
- ecosystem leverage
- frontier experimentation

Scoring Dimensions

Frontierness
How close is this to the edge?

Builder Signaling
Would frontier builders find this interesting?

Artifact Potential
Can this become something shareable?

Capability Gain
Will it teach something valuable?

Ecosystem Fit
Does it strengthen SEAS, OCII, Synapi, or future projects?

Delight
Would Yiya actually want to build it?
